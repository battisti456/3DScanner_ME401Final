# 3D Scanner Using Simple Mechatronics

This repository includes the written report and the code used for ME401: Mechatronics at Washington State University.

The focus of the project was to create a mechatronics device and report on it. For this project, the concept of using an IR distance sensor on a precisely controlled motorized platform for 3D scanning was decided upon. The report, [`final report.pdf`](final report.pdf) details the design of the device and its performance.

The device worked moderately well for general shapes, but did not have great precision.
